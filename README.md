# trueforge-jev-backlog

Synthetic demo data for the article "How to Run Jev Inside an Open Agent Harness."

The 300 issues in this repo (200 open, 100 closed) were generated by a script to look like a mid-size SaaS engineering backlog. They are not real bugs, and no real customer data is involved.

The demo's agent reads these issues through GitHub's MCP server and matches them against a separate list of customer requests. The generator, prompts, and analysis scripts are published separately with the article.
